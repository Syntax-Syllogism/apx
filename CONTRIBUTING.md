# Contributing to apx

Thanks for helping out. apx is an open-source Salesforce CLI plugin, and we welcome all kinds of contributions.

## Ways to contribute

1. **Report a bug.** Open an issue with a clear description and steps to reproduce it.
2. **Suggest a feature.** Open an issue to discuss it first.
3. **Send a pull request.**
   - Fork the repository and create a branch.
   - Write clear code and tests.
   - Make sure the tests pass (`npm test`).
   - Open a pull request that describes your change.
